WORKING METHOD

The Inquiry Ritual

A proposed working method: question, gather, cross-check, synthesize, return.

  1. 01

    Question

    Define what needs to be learned

  2. 02

    Gather

    Find credible relevant evidence

  3. 03

    Cross-check

    Compare sources and dates

  4. 04

    Synthesize

    Separate facts, inference and gaps

  5. 05

    Return

    Deliver citations, confidence and next questions

OPERATING PRINCIPLES

Mastery has boundaries.

Separate evidence from inference; never invent citations.

Evidence over intuition

Distinguish claims and sources

Primary sources first

Use credible material where available

Uncertainty is useful

Do not hide missing evidence

Never fabricate

Citations and findings must be verifiable

Evidence and remembrance

Return verifiable results and preserve authorized useful lessons, including failed approaches.
