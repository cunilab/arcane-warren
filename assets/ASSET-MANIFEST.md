# Arcane Warren — artwork checklist

All original placeholder slots remain. Replace them with your own artwork; no finished illustrations are generated by the website. The interactive architecture and workflow remain HTML.

## Replace an image

Run `python3 scripts/replace_asset.py assets/images/characters/veyra.svg /path/to/veyra.webp` from the repository root. The script updates the asset registry and regenerates the site using Node.js. SVG, PNG, JPEG and WebP are supported. Use the recommended aspect ratio. Shared assets are referenced from one registry.
