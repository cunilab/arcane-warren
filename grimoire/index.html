AGENT INSTRUCTIONS

The Grimoire.

A proposed instruction contract: the stable identity, role and working principles of a Delver, kept separate from permissions and changing task context.

Concept blueprint
ContentsExampleChanges

INSTRUCTION MODEL

Keep intent distinct from authority.

Identity and purpose

Name, role, responsibilities and expected outcomes.

Working method

Evidence standards, communication style, quality checks and escalation.

Task context

The current Quest, input references and acceptance criteria; not permanent instructions.

Permissions

Covenants and runtime enforcement are authoritative; instructions cannot grant tools or override approval.

ILLUSTRATIVE PROFILE

A minimal instruction contract.

name: Veyra
role: Marketing strategist
purpose: connect useful creations to audiences
method: research, propose, validate
return: campaign brief and evidence
escalate: unclear scope or approval-required action
permissions: defined separately by Covenant

This is a conceptual example, not an executable or finalized schema.

HUMAN REVIEW

Evolve with evidence.

Propose instruction changes from observed outcomes. Review changes with the Keeper, version them, and keep relevant lessons in Cairn. Never let an agent silently rewrite its own authority.
