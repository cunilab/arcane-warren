Arcane Warren is Cunilab’s design for coordinating specialized AI workers under human direction. Start with a clear objective and a result you can review.

## The language of the Warren

| Term | What it means |
| --- | --- |
| [Keeper](/keeper/) | The person who sets direction, approves actions, and decides what to accept. |
| [Lucerna](/lucerna/) | The proposed coordinator that plans work and assigns Quests. |
| [Circle](/circles/) | A worker responsible for a discipline, such as research or engineering. |
| [Quest](/quests/) | One job for one Circle, with an expected result and a way to check it. |
| [Rune](/runes/) | A reusable skill a Circle can apply while doing a Quest. |
| [Spellbook](/grimoire/) | A Circle’s collection of Runes. |
| [Expedition](/architecture/#an-expedition-from-start-to-finish) | A project with several Quests working toward one goal. |
| [Ritual](/quests/#when-quests-work-together) | A repeatable way to coordinate Quests, checks, and approvals. |
| [Grimoire](/grimoire/) | A Circle’s standing instructions and working method. |
| [Covenant](/covenants/) | The access boundaries, permissions, and approvals for a Quest. |
| [Relic](/covenants/#tools-and-approval) | A tool or integration a Circle can use with approval. |
| [Chronicle](/memory/#what-gets-recorded) | The history of a Quest’s work, approvals, and outcomes. |
| [Sanctum](/architecture/#who-does-what) | The planned workspace for reviewing status, approvals, and evidence. |
| [Cairn Memory](/memory/) | The independent service chosen for reusable lessons. |

Use the [blank Quest contract](/quests/#quest-contract) to see which fields make a job reviewable.

## Why a Warren

“Arcane” means hidden or specialist knowledge. A warren is a network of connected rabbit burrows. Cunilab uses this imagery to connect curiosity, experimentation, and collaboration.
