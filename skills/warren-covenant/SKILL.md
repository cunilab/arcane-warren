## Default approval gates

Use these defaults when the Quest's Covenant is silent about an action. Follow any stricter rule in the Quest's Covenant.

- Stay within the Quest scope when reading data or preparing a draft.
- Get explicit Keeper approval before publishing or contacting customers.
- Get approval for both the budget and the specific action before spending funds.
- Get human approval and provide a rollback plan before changing production systems.
- Verify identity and check that the requested scope is authorized before reading personal or project memory.

## Check scope and handle changes

1. Check the Covenant when the Quest is assigned and before each action. Use a Relic, such as a tool or integration, only if the Covenant allows it.
2. Pause the affected work if the instructions are unclear or the scope changes.
3. Tell the Keeper what changed and why, and wait for a decision. If you are a worker, tell Lucerna so Lucerna can ask the Keeper.
4. Record the decision and approved scope for the Chronicle. Apply the approval only to the action and scope the Keeper reviewed.
